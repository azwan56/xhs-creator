小红书博主专属创作智能体（Agent）流程管理手册

【终极进化版：风格固化 + 自我迭代 + 封面视觉框架 + 豆包大模型 + 阿里云部署】
💡 核心定位与技术底座
本系统是专属博主的终身进化型私人创作大脑与爆款交付工作台。系统全面接入【字节跳动火山引擎·豆包大模型（Doubao Ark API）】，并针对【阿里云基础设施（Serverless FC 3.0 与 ECS 容器化）】进行全栈生产级适配，实现风格 100% 固化、质感持续升级、3:4 视觉封面与文案一站式高效交付。

一、 核心升级设计理念与技术选型

  • 1. 核心模型引擎：豆包大模型（Doubao Ark API）：接入火山引擎方舟平台 Doubao-pro-32k/128k 与 Doubao-lite，具备长上下文、极低延迟流式输出（SSE）、卓越的中文语感与原生小红书爆款文风。
  • 2. 部署基础设施：阿里云（Alibaba Cloud）全栈适配：支持阿里云函数计算 FC 3.0 (Serverless 极低成本免运维) 与 ECS / 轻量应用服务器 (Docker 容器化) 双模式一键交付。
  • 3. 视觉优先与封面设计框架（Visual-First Engine）：小红书 70% 点击取决于封面，80% 留存取决于多页轮播。系统建立工业级 3:4 封面设计框架规范，文案生成即自动切片渲染为 1080×1440 高清图集。
  • 4. 动态反思进化（Reflective DNA Evolution）：采用「反思比对 ➔ 增量 DNA 补丁 ➔ 记忆择优锁定 ➔ 历史版本快照」机制，杜绝模型退化，只进不退。
  • 5. 多赛道自适应模态（Multi-Niche Adaptation）：内置商业财经、认知成长、好物测评、探店攻略等差异化叙事模型、专属视觉卡片主题与打分权重。
  • 6. 小红书算法质检闭环（Algorithm Quality Gate）：内置 CTR 点击预测、CES 完播度打分与违禁词/AI腔扫描，确保产出即为高流量达标内容。

1. 空间布局与三道安全红线

  • 标准比例与分辨率：3:4 黄金宽高比，输出 1080px × 1440px 高清分辨率。
  • 顶部安全区（Top 120px）：放置栏目胶囊徽章（Badge）、期数编号与副标。
  • 黄金焦点区（Y: 20% ~ 55%）：核心抓手大标题（8~14字，大字加粗，重点关键词高亮变色）。
  • 信息承载区（Y: 55% ~ 80%）：核心视觉锚点卡片（对比框/数据卡/操作界面/清单）。
  • 底部避让区（Bottom 180px - 绝对红线）：禁止放置任何核心文字或关键图表，避开小红书客户端常驻的作者头像、昵称与点赞覆盖。
  • 左右呼吸边距（Margin 60px~80px）：严格留白，杜绝文字贴边拥挤感。

三、 豆包模型接入与阿里云部署方案

1. 字节跳动火山引擎·豆包大模型（Ark API）规范

  • API 协议：标准 OpenAI 兼容协议，Base URL 为 https://ark.cn-beijing.volces.com/api/v3
  • 模型选型：Doubao-pro-32k/128k（复杂反思进化、长文拆解、深度逻辑）；Doubao-lite（毫秒级极速生成）
  • 传输特性：支持 SSE（Server-Sent Events）流式打字机响应，生成过程零等待

2. 阿里云部署交付架构

  • 方案 A：阿里云函数计算 FC 3.0（Serverless 推荐）：免买服务器、免运维、按量计费，内置 s.yaml 配置文件，支持一键命令自动化上线。
  • 方案 B：阿里云 ECS / 轻量应用服务器（Docker 容器化）：独立主机环境，内置 Dockerfile、docker-compose.yml 与 Nginx 反代配置，支持绑定域名与 SSL。

五、 六大核心模块功能深度规划

  • 1. 四大素材入库矩阵：对标爆款拆解库 + 个人真迹标杆库 + 灵感选题库 + AI爆款框架公式库。
  • 2. 创作者 DNA 永久锁定：段落呼吸感、Emoji 密度、专属词汇、负向避坑黑名单（拒绝 AI 腔）。
  • 3. 1:1 口播深度复刻与提词器：语速节奏、气口停顿标记 [停顿 0.5s]、【重音】、全屏平滑滚动提词器。

  • 5. 创作 Studio 与 3:4 渲染引擎：选题 × 4 维爆款矩阵 ➔ 小红书图文 + 1:1 口播稿 ➔ 3:4 高清图集一键打包 ➔ 算法质检打分。
